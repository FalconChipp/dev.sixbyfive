## Description

The dev.sixbyfive site has no syntax highlighting library installed (no Prism, Shiki, Highlight.js, etc.). Code blocks on the Intent page must be styled using inline CSS and the site's existing CSS variables only. Token-level coloring (keywords, strings, comments) is not available.

## Rationale

Adding a syntax highlighting library is a dependency decision that affects the whole site, not just the Intent page. That decision is out of scope for this work. The constraint keeps the page self-contained and avoids pulling in a dependency that may conflict with the site's build or SSR setup.

The acceptable approach is `<pre><code>` blocks with `background: var(--bg-raised)`, `border: 1px solid var(--border)`, monospace font, and muted text color. Language labels can be shown as styled overlays above the block. This is sufficient for the documentation purpose.
