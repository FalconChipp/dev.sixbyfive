## Description

All styling on the Intent page must use the existing CSS custom properties defined in `app/globals.css` (`--bg`, `--bg-raised`, `--bg-subtle`, `--text`, `--text-2`, `--text-3`, `--text-4`, `--accent`, `--accent-text`, `--border`, `--border-2`, `--radius`, `--font-mono`, `--font-display`, `--font-sans`, etc.) and the existing utility classes (`.wrap`, `.eyebrow`, `.eyebrow-accent`, `.display`, `.pill`, `.pill-live`, `.pill-accent`, `.btn`, `.btn-primary`, `.btn-secondary`, `.cs-grid`, `.work-row`).

No new selectors may be added to `globals.css` for this page.

## Rationale

The Intent page is one page among many. Adding global styles for one page risks naming conflicts and makes the stylesheet harder to reason about. All layout and spacing decisions can be expressed via inline styles on the page's own components using the token system — this is already the pattern used throughout the site.
