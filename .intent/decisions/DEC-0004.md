## Context

The Intent package ships a GitHub Action (`SixByFive/intent/.github/actions/intent-pr@main`) designed to post a comment on a PR showing relevant plans and decisions for the diff. This requires a pull request to exist — it uses `context.issue.number` to post the comment.

The dev.sixbyfive repo uses a direct push to main workflow with no PRs. The PR comment action would never trigger and has no target to comment on.

## Decision

Two workflows. `intent.yml` runs `intent validate` on every push to main — exits non-zero on schema errors or broken cross-references. `intent-pr.yml` runs the PR comment action on pull requests, posting relevant context as a comment on the diff.

## Consequences

- Broken `.intent/` cross-references or invalid frontmatter will fail the CI job on main
- PRs get contextual intent commentary automatically when the PR workflow triggers
- The validate step covers the direct-push-to-main workflow; the PR step covers any future branch-based work
