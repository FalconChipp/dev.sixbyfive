## Context

The site has two sections that Intent could reasonably belong to: `/work` (products and open source projects the studio has built) and a hypothetical `/open-source` section that doesn't currently exist. A third option would be `/tools`, but Intent is a developer package not a browser-based tool.

## Decision

Route the page to `/work/intent` and list it in `app/work/page.js` alongside TCGDex and the 3D Printing Portal. Add it to the homepage work preview (`app/page.js`) at position 0 with an "Open source" badge.

No new top-level route or section is introduced.

## Consequences

- Keeps routing simple — no new section to maintain or explain
- Intent sits naturally alongside TCGDex, which is also an open source project the studio maintains
- If more open source packages are published, they would follow the same pattern under `/work` or a future `/open-source` section could be introduced then
- The homepage work preview now has four items (Intent, TCGDex, SixByFive TCG Suite, 3D Printing Portal)
